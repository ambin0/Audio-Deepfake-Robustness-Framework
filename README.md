# Audio-Deepfake-Robustness-Framework
MSc Cyber Security dissertation project

## Research Question
How do realistic communication degradations affect the performance and robustness of deep learning-based audio deepfake detection frameworks models?

## Dataset
ASVsoof 2019 Logical Access.

## Models
-CNN
-LCNN
-LFCC-GMM reference baseline

## Controlled Degradations
Background noise
Mp3 compression
Reduced sampling rate

## Evaluation
Primary evaluation will use:
-Equal Error Rate (EER)
-ROC-AUC

Supporting metrics will include:
-Accuracy
-Precision
-Recall
-F1-score
- DET curves
- Confusion matrices

## Reproducibility
The project will use fixed random seed, version-controlled configurations, and controlled datatset partitioning.
